MotionField

Send web media to your local MotionField studio. The key lives in this browser's chrome.storage.local only - it never syncs, and it is attached to requests only when they go to the URL below.

Create a key in the app under Settings → API keys. It's shown once; paste it here. The key is saved only after the Check below succeeds against it.

http:// sends the key in the clear. Loopback (localhost / 127.x / ::1) is always allowed; anything else needs this tick.

not configured

By default the extension can only reach MotionField on localhost. Granting http(s)://*/* is needed for two things:

  • connecting to an MotionField server that isn't on this machine (a LAN or hosted URL);
  • reading media straight off websites - without it, right-clicked images/videos on other origins can't be fetched and Send to MotionField will report "can't read that media".
