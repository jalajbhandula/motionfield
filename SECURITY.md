# Security policy

Report suspected vulnerabilities privately to the repository maintainer. Use GitHub's Security → Report a vulnerability when available. If that option is unavailable, request a private reporting channel without posting exploit details, credentials or personal data in a public issue.

Include the affected revision, a minimal reproduction, expected and observed behavior, and the likely impact. Redact tokens and private media.

MotionField can execute local model workflows and invoke external binaries. Keep the application and ComfyUI on trusted interfaces, review custom nodes before installation, and use the application's authentication, ownership and license checks. Do not expose a development server or raw ComfyUI service publicly without appropriate access controls.

Never upload a person’s voice or likeness without the rights and consent required for the intended use. Model licenses remain separate from MotionField's MIT license.
