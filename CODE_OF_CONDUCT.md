# Code of conduct

Treat contributors and users with respect. Give specific, constructive feedback and focus disagreements on the work.

Harassment, discriminatory abuse, threats, impersonation, deliberate disclosure of private information and unwanted sexual attention are not acceptable. Do not use project discussions to distribute non-consensual personal media or credentials.

Maintainers may remove harmful content, restrict participation or close discussions that violate these expectations. Report concerns privately to a repository maintainer; avoid publishing another person's private information in a report.

These expectations apply to repository issues, pull requests and other project-managed spaces.
