# Product

## Register

product

## Users

Creators and developers evaluating an open-source creative studio, plus contest
judges for the Comfy "Open Source" challenge. They land on tool surfaces to get
one job done fast: drop a clip, swap a person, re-edit, generate. They judge
quality in seconds by how the surface looks and whether the first action is
obvious.

## Product Purpose

A local-first, open-weights creative studio: image/video generation, person and
object swap, re-edit, camera moves, character consistency, dubbing, effects,
ads. Every surface must make a verifiable claim (labels match real executors)
and run on the local pipeline or clearly-flagged cloud paths. Success = the
tool is obvious in 5 seconds and the result preview is always visible.

## Brand Personality

Competent, honest, plain-spoken. Plain-English names only — no codenames, no
borrowed brand vocabulary. 3 words: direct, capable, unpretentious.

## Anti-references

- Competitor branding, product names, and "clone of" framing (clean-room rule;
  matching or beating best-in-class UI quality is the goal, copying copy is not)
- Generic AI-dashboard look: left sidebar crammed with tools, tiny "+" upload
  boxes, single-column form dumps with dead right halves
- Purple/blue AI gradients, glassmorphism-as-default, identical card grids
- Fake marketing claims ("any length", unbuilt models in labels)

## Design Principles

- One job per surface; the first action is a big dropzone, not a form
- Split layout on tool pages: inputs left, live preview/result right; never a
  dead column
- Progressive disclosure: drafts, batch, advanced options collapse until needed
- Show, don't tell: result compare, live progress, real estimates
- Labels are claims: only name what is actually wired and verified

## Accessibility & Inclusion

WCAG AA contrast minimum, visible focus rings, keyboard-reachable controls,
`prefers-reduced-motion` respected, 44px touch targets on interactive elements.
